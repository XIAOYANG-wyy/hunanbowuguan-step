# 三湘器物 · 流光

Three.js 全屏文物粒子互动原型。点云从六件文物的单张图片采样并加入轻微深度生成，因此是伪 3D 粒子造型，不是真实的 3D 扫描网格；需要真实三维旋转细节时，应替换为扫描模型或多角度照片。摄像头手势使用浏览器端 MediaPipe Hand Landmarker，不会上传摄像头视频。图片素材来自用户提供的截图，藏品名称为演示用暂拟名称。

## 本地运行

```sh
python3 -m http.server 4173
```

访问 <http://localhost:4173>。首次开启手势需联网载入识别模型，并允许摄像头权限；生产环境应使用 HTTPS。

## Windows 11 客户端

双击 `run-windows.bat`。脚本会检查 Python 3；如果没有安装且系统提供 `winget`，会自动安装 Python 3.12，然后启动本地网页并打开默认浏览器。首次启动需要联网并确认 winget 的安装提示。运行期间不要关闭最小化的 `Hunan Exhibit Server` 窗口；关闭它即可停止服务。

如果系统没有 `winget`，请先从 <https://www.python.org/downloads/windows/> 安装 Python 3，再运行脚本。首次体验摄像头手势还需要允许浏览器摄像头权限并联网下载 MediaPipe 模型。

## 手势

- 张开手掌：粒子扩散
- 握拳：粒子聚合
- 伸出食指：粒子跟随手部移动
- 食指与中指同时伸出：切换粒子颜色
- 鼠标拖动：旋转视角；底部选项切换六件文物
- 无摄像头时可用屏幕按钮触发扩散、聚合和变色
